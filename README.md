# CodeCraft Platform

A clean, responsive programming education platform designed to help students learn web and mobile development through structured tracks and hands-on courses.

## Features

- **Structured Learning Tracks:** Dedicated roadmaps for Frontend, Backend, and Mobile Development.
- **Interactive Course Explorer:** Filter courses by track with a custom Vanilla JavaScript slider.
- **Authentication Modals:** Clean Login and Register popup modals with form validation and keyboard/backdrop close support.
- **Responsive Design:** Built mobile-first with a sticky navigation bar, smooth scrolling, and active section highlighting.

## Tech Stack

- **HTML5:** Semantic structure and accessible forms.
- **CSS3:** Custom CSS variables, Flexbox, Grid layouts, and responsive media queries.
- **Vanilla JavaScript:** DOM manipulation for modals, track filtering, course slider, and scroll spy.
- **Assets:** Custom SVG brand logo and optimized local imagery.
